Four PNG files go into this folder. The README already links them:

| File | What to show |
|---|---|
| `01-recipes.png` | Main window (`/brpp show`): profession filter and subcategory dropdown open, a few recipes listed, search box filled. |
| `02-crafters.png` | A recipe clicked: the popup with reagents and the crafter list, own guild plus at least one blue `<Partner guild>` entry marked *online*. Open the whisper menu if you can. |
| `03-partner-setup.png` | Chat frame after `/brpp partner create` (code visible, blur it before upload!) and `/brpp partner status`. |
| `04-admin.png` | The Admin tab of the main window with the *Connect guild members* button visible. |

Tips: hide other addon bars, use one resolution for all four, crop to the window, and blur the invite code.
